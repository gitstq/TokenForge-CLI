# Contributing to TokenForge-CLI

Thank you for your interest in contributing to TokenForge-CLI!

## Development Setup

```bash
git clone https://github.com/gitstq/TokenForge-CLI.git
cd TokenForge-CLI

# Run tests
python -m unittest discover tests -v
```

## Commit Convention

Please use Angular commit conventions:

```
feat: add new compression strategy
fix: resolve token estimation accuracy issue
docs: update README documentation
refactor: optimize compression pipeline
test: add unit tests for exporter module
chore: update .gitignore
```

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes (`git commit -m 'feat: add your feature'`)
4. Push to the branch (`git push origin feature/your-feature`)
5. Create a Pull Request

## Reporting Issues

When filing an issue, please include:

- Python version
- Operating system
- Steps to reproduce
- Expected vs actual behavior
